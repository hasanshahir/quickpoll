# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in QuickPoll, please do not disclose it publicly or open a public GitHub issue.

Please report vulnerabilities privately via:
1. **GitHub Security Advisory**: Navigate to the **Security** tab of this repository, select **Advisories**, and click **Report a vulnerability**.
2. **Email**: If GitHub Private Vulnerability Reporting is unavailable, email security concerns to the repository maintainer.

### What to Include in Your Report
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof of concept.
- Any suggested mitigations or patches.

### Response Time
We will acknowledge receipt of your report within 48 hours and provide updates as the issue is investigated and addressed.
